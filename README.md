# Weatherly

Open-Meteo 기반 반응형 날씨 웹앱입니다.

## 주요 기능

- 도시 검색 및 변경
- GPS 현재 위치 날씨
- 현재 날씨와 오늘의 상세 지표
- 현재부터 24시간 시간별 예보
- 7일간 날씨
- 주간 최고기온 그래프
- 반응형 카드 레이아웃
- shadcn/ui 방식의 UI 컴포넌트
- Lucide React 아이콘

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 빌드 확인

```bash
npm run build
npm start
```

Open-Meteo API는 별도 API 키 없이 사용합니다. 서비스 공개 전에는 Open-Meteo 이용 조건을 확인하세요.
